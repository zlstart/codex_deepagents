# 渠道销售小结

数据来源：`orders.csv`（4 笔订单），金额单位为元。

## 各渠道金额

| 渠道 | 订单数 | 销售额(元) | 占比 |
| ---- | ------ | ---------- | ---- |
| 门店 | 2      | 1700       | 48.6% |
| 线上 | 1      | 800        | 22.9% |
| 合作 | 1      | 1000       | 28.6% |

## 合计

- 各渠道金额相加：1700 + 800 + 1000 = **3500 元**
- 订单明细逐笔相加：1200 + 800 + 500 + 1000 = **3500 元**
- 两种口径一致，总计销售额 **3500 元**

## 说明

- 汇总方式：按“渠道”字段分组，对销售额求和；门店渠道包含第 1、3 两笔订单。
- 占比按合计 3500 元计算，四舍五入保留一位小数；48.6% + 22.9% + 28.6% = 100.1%，其中 0.1 个百分点为舍入尾差，不影响金额合计。
