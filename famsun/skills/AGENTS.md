# FAMSUN engineering conventions

Use SI units unless the user specifies others. Clarify whether dimensions and material properties are supplied, measured, or illustrative. For generated models, keep the editable source alongside the viewer-ready export. Give components stable names across assembled and exploded views. For numerical work, record inputs and tolerances and report at least one measured invariant or independent check.

Treat each session as a private engineering workspace. Keep generated assets and temporary experiments in this session. Use the user's language in the final deliverables.
